AI Memory Search

AI Memory Search is a private intelligent search application for Android that allows users to search across documents, images, email messages and supported email attachments from a single interface.

AI-powered indexing and semantic search are performed locally on the user's device. When email search is enabled, AI Memory Search accesses authorized email services only to synchronize the content required for the user's local search index.

AI Memory Search does not use email content for advertising and does not upload the user's private search index to developer-operated servers.

Documents Search supported documents using local indexing and semantic search.
Images Find locally indexed images using AI-assisted semantic matching.
Email Search authorized email messages and supported attachments from the local index.
Local AI AI models and the private search index operate locally on the user's device where supported.
